# 등기정보광장 Open API

출처는 대한민국 법원 등기정보광장이다. 포털은 [data.iros.go.kr](https://data.iros.go.kr)이고, 이용 안내는 [Open API 개요](https://data.iros.go.kr/rp/oa/openOapiIntro.do)에 있다.

이 디렉터리는 포털에서 받은 명세서 209건을 호출 계약으로 옮긴 것이다. 서비스 ID는 `0000000001`에서 `0000000224`까지 분포한다. 

| 파일 | 내용 |
| --- | --- |
| [catalog.json](catalog.json) | 공통 호출과 서비스 209건 |
| [messages.json](messages.json) | 서비스마다 동일하게 붙은 메시지 22개 |

## 범위

집계 단위는 지역과 기간이다. 신청 건수, 부동산 수, 명의인 수, 평균 금액이 나온다. 물건 하나의 등기사항증명서는 인터넷등기소에서 문서로 받는다.

갱신주기는 일 159건, 월 50건이다. 분류의 마지막이 비어 있는 명세서는 빈 단계를 뺐다.

## 호출

209건의 주소는 같고, 쿼리 `id`만 다르다.

```text
GET https://data.iros.go.kr/openapi/cr/rs/selectCrRsRgsCsOpenApi.rest
```

공통 쿼리는 `id`, `reqtype`, `key`다. `reqtype`은 `xml` 또는 `json`이고 기본값은 `xml`이다. 서비스별 인자는 `catalog.json`의 `params`에 있다. 명세서의 호출 제한은 하루 1,000회, 한 번 요청의 결과는 1,000건이다. 포털 안내도 하루 1,000건이라고 적혀 있다.

인증키는 서비스마다 따로 신청한다. 포털 안내는 승인 없이 바로 쓸 수 있고, 3개월간 이용 내역이 없으면 키가 삭제된다고 적는다. 키는 저장소에 넣지 않는다.

키를 비운 `id=0000000001&reqtype=json` 호출은 아래 껍데기로 `APIERROR-0005`를 돌려줬다. 문구는 [messages.json](messages.json)과 같다. 정상 결과 행이 이 껍데기 어디에 붙는지는 인증키를 넣은 호출에서 확인한다.

```json
{
  "result": {
    "head": {
      "returnCode": "APIERROR-0005",
      "returnMessage": "인증키값이 없습니다.요청인자 중 Key를 확인하십시오.",
      "totalCount": "0"
    }
  }
}
```

## 인자

기본인자와 요청인자, 출력값의 타입은 모두 `STRING`이다. 출력 표에는 필수 칸이 없어서, `fields.required`는 명세서 HTML의 항목 속성에서 가져왔다. `sex`와 `bdataAge`만 29개 서비스에서 필수가 아니다.

메시지 22개는 서비스 209건에 같은 표로 붙어 있다. 설명 속의 파라미터 이름은 그 서비스의 요청인자와 다를 수 있다. `0000000001`은 `search_regt1_name_api`를 쓰지만, 표에는 `search_regn1_name_api` 오류도 들어 있다. `APIERROR-0014`는 최근 3년만 제공한다고 적혀 있다.
